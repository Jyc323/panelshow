# Roadmap

What is planned next. Ideas and pull requests are welcome.

## Models and providers
- [ ] Other OpenAI-compatible providers: OpenRouter, LM Studio
- [ ] Function calling for models that support it, for more reliable file and link requests

## Working with code
- [ ] Members propose changes to a shared folder as diffs you can apply
- [ ] Preview member-written HTML pages in a sandbox
- [ ] Members edit each other's files, with version history

## Conversations
- [ ] One-click presets: Council, Critique, Debate
- [ ] Add a member in the middle of a chat ("someone who knows X")
- [ ] Summarise old messages instead of dropping them in long chats
- [ ] Web search for members
- [ ] Judges open the links and files a reply cites

## Media
- [ ] Images and 3D models as attachments
- [ ] Frames and sound from YouTube / Bilibili videos
- [ ] Members that generate images or video for the others to critique

## Cost and sharing
- [ ] Costs in dollars and a spending cap per room
- [ ] Share a session as a read-only page; export a verdict as an image
- [ ] Optional hosted version (each visitor brings a key)
